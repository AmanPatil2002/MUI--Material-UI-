# 📘 Social Media UI Clone

A responsive **Social Media UI Clone** built with **React**, **Vite**, and **Material UI (MUI)**. This project recreates the layout of a modern social networking application with a responsive navigation bar, sidebar, feed, and right sidebar.

> **Note:** This project is a frontend UI clone created for learning and practice purposes. It does not replicate any proprietary functionality of any social media platform.

---

## 🚀 Features

- 🏠 Responsive Navigation Bar
- 📑 Left Sidebar Navigation
- 📝 Create Post Section
- 📰 Dynamic Feed with Fake Posts
- 👤 User Avatars
- ❤️ Like, 💬 Comment, and ↗️ Share Actions
- 🖼️ Random Images using Picsum
- 👥 Online Friends Section
- 📷 Latest Photos Gallery
- 💬 Latest Conversations
- 🌙 Material UI Components
- 📱 Responsive Layout
