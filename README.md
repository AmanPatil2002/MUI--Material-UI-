# Material UI (MUI) Learning Projects

A collection of React projects built while learning **Material UI (MUI)**. This repository contains different examples demonstrating MUI components, layouts, theming, responsiveness, and modern UI development using React and Vite.

## 🚀 Tech Stack

- React.js
- Vite
- Material UI (MUI)
- JavaScript (ES6+)
- CSS

## 📂 Folder Structure


Each folder contains a separate MUI practice project.

## 🛠️ Installation

Clone the repository:

```bash
git clone https://github.com/AmanPatil2002/Material-UI.git
```

Go to the project folder:

```bash
cd MUI
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
